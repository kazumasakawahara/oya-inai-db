0先に覚える、たった1つの作法 ——「完全終了」

なぜ、これを最初に書くのか

Windows の Claude は、右上の「×」を押しても終了しません。画面が消えるだけで、中身は動き続けています。

そして動いたまま設定を書き換えると、書いた内容が黙って消えることがあります。エラーも警告も出ません。「たしかに書いたのに、開き直したら元に戻っていた」——これで何時間も溶かす方が実際にいます。

設定をさわる前と後には、必ず完全終了してください。

手順1 ── タスクトレイから終了する

  1. 画面右下、時計の左あたりの ^（上向きの矢印）をクリックします。隠れているアイコンが出てきます
  2. その中の Claude のアイコンを右クリックします
  3. 出てきたメニューから 「Quit」または「終了」を選びます

手順2 ── それでも残っていないか確かめる

  1. Ctrl + Shift + Esc を同時に押します（タスクマネージャーが開きます）
  2. 一覧から 「Claude」を探します
  3. あれば右クリック → 「タスクの終了」
  4. いくつも並んでいたら、全部終了してください
一覧に Claude が1つも無くなれば、完全終了できています。あとは、デスクトップやスタートメニューから普通に開き直してください。
Mac の場合：ウィンドウを閉じるだけでは同じく終了しません。command + Q を押してください。Dock の Claude アイコンの下の点が消えていれば終了しています。

1「差込口」の話

Claude は、はじめは何も見えていません。あなたのパソコンのファイルも、データベースも、Claude からは存在しないのと同じです。そこに差込口を1つ挿すと、あなたが決めたフォルダだけが見えるようになります。この差込口を MCP と呼びます。名前は覚えなくて結構です。

差込口つなぐ相手できるようになること
filesystemObsidian の Vault語りの原本を保存し、ページを書く
neo4j支援データベース禁忌・ケア・期限を構造化して登録する

この文書で入れるのは上の1つだけです。

2最初に1回だけ決めること

ここで指定した場所が、Claude の手の届く範囲のすべてです。

  • 見せる：Obsidian の Vault フォルダ（必須）
    例：C:\Users\あなたの名前\Documents\Obsidian\あなたのVault名
  • 見せる：スキルの置き場所（おすすめ）
    C:\Users\あなたの名前\.claude\skills
    ここを指定しないと、Claude は「スキルを入れておきますね」と言えません
  • 見せない：Claude 自身の設定フォルダ
    ここだけはご自身の手で。アプリの設定を壊せる唯一の場所です。渡さなくても、Claude が「この文字をここに貼ってください」と示すので困りません
Vault の場所が分からないときは：Obsidian の左下の歯車 →「Vault」→「Vault フォルダを開く」でエクスプローラーが開きます。アドレス欄をクリックするとフルパスが文字で出ますので、コピーして控えてください。

3filesystem を入れる

まず経路 A を試してください。Windows では経路 B に落とし穴があるので、A で済むならその方が安全です。

経路 A ── 一覧から追加する（おすすめ）

  1. Claude Desktop を開きます
  2. 左下のご自身のお名前をクリックします
  3. 設定を開きます
  4. 拡張機能（コネクタ）の一覧を開きます
  5. 検索欄に filesystem と入力します
  6. 出てきたものの 「追加」を押します
  7. 2章で決めたフォルダを指定します
  8. 0章の手順で完全終了 → 起動します
これで終わりです。Node.js などを入れる必要はありません。一覧に filesystem が見当たらない場合だけ、経路 B へ進んでください。

経路 B ── 設定ファイルに書く（一覧に無い場合）

⚠️ Windows の落とし穴：設定ファイルが2か所にあることがあります

Windows 版では、設定画面の「Edit Config」ボタンが開くファイルと、アプリが実際に読んでいるファイルが別物になっている場合があります（インストーラの方式によります）。片方に正しく書いても、まったく効きません。しかもエラーは出ません。

ですので、まず「アプリが実際に読んでいる方」を確かめてから書きます。

手順1 ── どちらが本物か確かめる

  1. Windows + R を押します（「ファイル名を指定して実行」が開きます）
  2. 次の文字をそのままコピーして貼り付け、Enter を押します
    %LOCALAPPDATA%\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming\Claude
  3. フォルダが開いたら、そこが本物です。この中の claude_desktop_config.json を編集してください
  4. 「見つかりません」と出たら、もう一方が本物です。同じ手順で次を貼り付けてください
    %APPDATA%\Claude

手順2 ── ファイルを開く

claude_desktop_config.json を右クリック →「プログラムから開く」→ メモ帳。ファイルが無ければ、そのフォルダで新規テキストファイルを作り、名前を claude_desktop_config.json にしてください（拡張子 .txt が付かないよう注意）。

手順3 ── 中身を書く

すでに何か書かれている場合は、"mcpServers" の中に足す形にしてください（既存の内容は消さないでください）。まっさらな場合は、次をそのまま貼って、パスだけご自分のものに置き換えます。

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "--prefer-offline",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\あなたの名前\\Documents\\Obsidian\\あなたのVault名",
        "C:\\Users\\あなたの名前\\.claude\\skills"
      ]
    }
  }
}

⚠️ 円マーク（＼）は「2つ重ね」です

エクスプローラーでは C:\Users\... と1つですが、このファイルの中では C:\\Users\\... と2つ書きます。ここを間違えると動きません。いちばん多い失敗です。

Mac の場合は重ねません。そのまま /Users/あなたの名前/Obsidian/Vault名 と書きます。

手順4 ── 保存して、完全終了 → 起動

メモ帳で上書き保存したら、0章の手順で完全終了し、開き直してください。

経路 B には Node.js（npx）が必要です。入っていない場合は nodejs.org から LTS 版を入れて、もう一度やり直してください。

4入ったかどうか、確かめる

その1（おすすめ）：チャット入力欄の左下の「+」を押し、「コネクタ」を開きます。一覧に filesystem が出ていれば成功です。

その2：Claude にこう頼んでください。

Vault の schema.md を読んでください。

中身が返ってくれば成功です。どちらもだめなときは、8章をご覧ください。

5ここから先は、Claude に聞いてください

もう、ご自身で調べる必要はありません。やりたいことを、そのまま日本語で言えば大丈夫です。

Neo4j の差込口を足したいです。設定に貼る文字列を作って、貼る場所も教えてください。
oya-inai のスキル3つを、スキルのフォルダに入れてください。
こんな画面が出ました。どうすればいいですか。（画面をそのまま貼る）

うまくいかないときも、エラーの文字をそのまま貼って聞いてください。意味を読み解いて、次の一手を出してくれます。

6Claude ができること／ご自身の手が要ること

Claude ができることご自身の手が要ること
見せたフォルダのファイルを読む・書くClaude の完全終了と再起動
設定に貼る文字列を作る一覧の「追加」ボタンを押す
スキルをスキルのフォルダに置く設定ファイルへの貼り付け・保存
エラーの意味を説明し、直し方を示すパスワードの入力
Vault のページを型に沿って書くDocker の起動（neo4j を使う場合）

右側は、どれも「押す・貼る・打つ」だけです。考える仕事は左側が引き受けます。

7neo4j は「両方の仕組みを使う方だけ」

Obsidian の Vault だけで使う方は、ここから先は不要です。

支援データベースも併せて使う場合は、差込口に加えてデータベース自体を動かしておく必要があります（Docker を使います）。filesystem より一段重い作業なので、Vault の方が動いてから着手してください。そのときは、5章のとおり Claude に聞けば案内されます。

8うまくいかないとき

上から順に確かめてください。多い順に並べてあります。

1

完全終了していない

いちばん多い原因です。「×」で閉じただけになっていませんか。0章の手順で、タスクマネージャーから Claude が消えたことまで確かめてください。

2

円マークが1つになっている（経路 B）

設定ファイルの中では C:\\Users\\... と2つ重ねます。1つだと動きません。

3

設定ファイルを間違えている（経路 B）

書いても何も変わらないときは、もう一方のファイルが本物かもしれません。3章の手順1に戻って、両方の場所を確かめてください。

4

一覧から追加したのに、設定ファイルに出てこない

故障ではありません。一覧から入れたものと設定ファイルに書いたものは別の場所に保存されます。片方に出てくるものは、もう片方には出てきません。どちらの入れ方でも動きます。

5

フォルダが見つからないと言われる

綴りを確認してください。空白や日本語が入っていても構いませんが、一字一句そのままである必要があります。

6

npx が無いと言われる（経路 B）

Node.js が入っていません。nodejs.org の LTS 版を入れてから、完全終了 → 起動でやり直してください。

7

それでもだめなとき ── 記録を見る

Windows + R で %APPDATA%\Claude\logs を貼り付けると記録のフォルダが開きます。mcp.log と mcp-server-filesystem.log の中身をそのまま Claude に貼り付けて「これはどういう意味ですか」と聞いてください。
