# MCP の設定 — ご自身の手が要るのは、最初の1つだけです

> **草稿です（2026-08-11）。**導入を案内する立場の方の確認を受ける前の版です。
> **Windows を主として書いています。**Mac の方は各章の「Mac の場合」をご覧ください。

---

## 読む前に（30秒）

この文書でやることは、**たった1つ**です。

**Claude に、Obsidian のフォルダを見せる設定を入れる。**

これさえ通れば、あとは Claude 自身に聞きながら進められます。データベースを足すのも、スキルを入れるのも、エラーの読み方も、Claude が案内します。

ただし、**その前に覚えていただきたい作法が1つだけ**あります。次の章です。ここを飛ばすと、何をやってもうまくいきません。

---

## 0. 先に覚える、たった1つの作法 ——「完全終了」

### なぜ最初にこれを書くのか

Windows の Claude は、**右上の「×」を押しても終了しません。**画面が消えるだけで、中身は動き続けています。

そして、**動いたまま設定を書き換えると、書いた内容が黙って消えることがあります。**エラーも警告も出ません。「たしかに書いたのに、開き直したら元に戻っていた」——これで何時間も溶かす方が実際にいます。

ですから、**設定をさわる前と後には、必ず完全終了**してください。

### Windows での完全終了のしかた

**手順1：タスクトレイから終了する**

1. 画面**右下**、時計の左のあたりに **`^`（上向きの矢印）**があります。これをクリックすると、隠れているアイコンが出てきます
2. その中の **Claude のアイコンを右クリック**します
3. 出てきたメニューから **「Quit」または「終了」**を選びます

**手順2：それでも残っていないか確かめる**

1. キーボードで **`Ctrl` + `Shift` + `Esc`** を同時に押します（タスクマネージャーが開きます）
2. 一覧から **「Claude」** を探します
3. あれば右クリック →**「タスクの終了」**
4. **いくつも並んでいたら、全部終了してください**

一覧に Claude が1つも無くなれば、完全終了できています。

**手順3：改めて起動する**

デスクトップやスタートメニューから、普通に開き直してください。

> **Mac の場合**：ウィンドウを閉じるだけでは同じく終了しません。**`command` + `Q`** を押してください。Dock の Claude アイコンの下に点が消えていれば終了しています。

## 1. 「差込口」の話（1分）

Claude は、はじめは何も見えていません。あなたのパソコンのファイルも、データベースも、Claude からは存在しないのと同じです。

そこに**差込口を1つ挿す**と、あなたが決めたフォルダだけが見えるようになります。この差込口のことを MCP と呼びます。名前は覚えなくて結構です。

| 差込口 | つなぐ相手 | できるようになること |
|---|---|---|
| **filesystem** | Obsidian の Vault フォルダ | 語りの原本を保存し、ページを書く |
| neo4j | 支援データベース | 禁忌・ケア・期限を構造化して登録する |

**この文書で入れるのは、上の1つだけです。**下の neo4j は、両方の仕組みを使う方だけが、後から足します（→ 7章）。

---

## 2. 最初に1回だけ決めること —— どのフォルダを見せるか

差込口を挿すとき、「どのフォルダを見せるか」を指定します。**ここで指定した場所が、Claude の手の届く範囲のすべてです。**

**見せるフォルダ**

- **Obsidian の Vault フォルダ**（必須）
  - Windows の例：`C:\Users\あなたの名前\Documents\Obsidian\あなたのVault名`
  - Mac の例：`/Users/あなたの名前/Obsidian/あなたのVault名`
- **スキルの置き場所**（おすすめ）— スキルも Claude に入れてもらいたい場合
  - Windows：`C:\Users\あなたの名前\.claude\skills`
  - Mac：`/Users/あなたの名前/.claude/skills`
  - ここを指定しておかないと、Claude は「入れておきますね」と言えません

**見せないフォルダ**

- **Claude 自身の設定フォルダ** — ここだけはご自身の手で扱ってください。Claude がアプリの設定を壊せる唯一の場所です。渡さなくても、Claude が「この文字を、ここに貼ってください」と示してくれるので困りません

> **Vault の場所が分からないときは**：Obsidian を開いて、左下の歯車 → 「Vault」→ 「Vault フォルダを開く」でエクスプローラーが開きます。そのアドレス欄をクリックすると、フルパスが文字で出ます。コピーして控えておいてください。

## 3. filesystem を入れる

やり方は2通りあります。**まず経路 A を試してください。**Windows では経路 B に落とし穴があるので、A で済むならその方が安全です。

### 経路 A —— 一覧から追加する（おすすめ）

1. Claude Desktop を開きます
2. **左下のご自身のお名前**をクリックします
3. **設定**を開きます
4. **拡張機能（コネクタ）**の一覧を開きます
5. 検索欄に **`filesystem`** と入力します
6. 出てきたものの **「追加」**を押します
7. 2章で決めたフォルダを指定します
8. **0章の手順で完全終了 → 起動**します

これで終わりです。**Node.js などを入れる必要はありません。**

一覧に `filesystem` が見当たらない場合だけ、経路 B へ進んでください。

### 経路 B —— 設定ファイルに書く（一覧に無い場合）

> **⚠️ Windows の落とし穴：設定ファイルが2か所にあることがあります**
>
> Windows 版では、**設定画面の「Edit Config」ボタンが開くファイル**と、**アプリが実際に読んでいるファイル**が別物になっている場合があります（インストーラの方式によります）。片方に正しく書いても、まったく効きません。しかもエラーは出ません。
>
> ですので、**まず「アプリが実際に読んでいる方」を確かめてから**書きます。

**手順1：どちらのファイルが本物か確かめる**

1. キーボードの **`Windows キー` + `R`** を押します（「ファイル名を指定して実行」が開きます）
2. 次の文字を**そのままコピーして貼り付け**、Enter を押します

   ```
   %LOCALAPPDATA%\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming\Claude
   ```

3. **フォルダが開いたら**、そこが本物です。この中の `claude_desktop_config.json` を編集してください
4. **「見つかりません」と出たら**、もう一方が本物です。同じ手順で次を貼り付けてください

   ```
   %APPDATA%\Claude
   ```

**手順2：ファイルを開く**

`claude_desktop_config.json` を右クリック →「プログラムから開く」→ **メモ帳**。
ファイルが無ければ、そのフォルダで新規テキストファイルを作り、名前を `claude_desktop_config.json` にしてください（拡張子 `.txt` が付かないよう注意）。

**手順3：中身を書く**

すでに何か書かれている場合は、**`"mcpServers"` の中に足す**形にしてください（既存の内容は消さないでください）。まっさらな場合は、次をそのまま貼って、パスだけご自分のものに置き換えます。

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "--prefer-offline",
        "@modelcontextprotocol/server-filesystem",
        "C:\\Users\\あなたの名前\\Documents\\Obsidian\\あなたのVault名",
        "C:\\Users\\あなたの名前\\.claude\\skills"
      ]
    }
  }
}
```

> **⚠️ 円マーク（バックスラッシュ）は「2つ重ね」です。**
> エクスプローラーでは `C:\Users\...` と1つですが、このファイルの中では **`C:\\Users\\...` と2つ**書きます。ここを間違えると動きません。**いちばん多い失敗**です。

**Mac の場合**は重ねません。そのまま `/Users/あなたの名前/Obsidian/Vault名` と書きます。

**手順4：保存して、完全終了 → 起動**

メモ帳で上書き保存したら、**0章の手順で完全終了**し、開き直してください。

> 経路 B には Node.js（`npx`）が必要です。入っていない場合は、[nodejs.org](https://nodejs.org/) から LTS 版を入れてから、もう一度やり直してください。

## 6. Claude ができること／ご自身の手が要ること

ここを知っておくと、「頼んだのにやってくれない」で止まらずに済みます。

| Claude ができること | ご自身の手が要ること |
|---|---|
| 見せたフォルダのファイルを読む・書く | **Claude の完全終了と再起動** |
| 設定に貼る文字列を作る | 一覧の「追加」ボタンを押す |
| スキルをスキルのフォルダに置く（見せていれば） | 設定ファイルへの貼り付け・保存 |
| エラーの意味を説明し、直し方を示す | パスワードの入力 |
| Vault のページを型に沿って書く | Docker の起動（neo4j を使う場合） |

**右側は、どれも「押す・貼る・打つ」だけ**です。考える仕事は左側が引き受けます。

## 7. neo4j は「両方の仕組みを使う方だけ」

**Obsidian の Vault だけで使う方は、ここから先は不要です。**読み飛ばして構いません。

支援データベース（Neo4j）も併せて使う場合は、差込口に加えて**データベース自体を動かしておく必要があります**（Docker を使います）。filesystem より一段重い作業なので、**Vault の方が動いてから**着手してください。

そのときは、5章のとおり Claude に聞いてください。設定に貼る文字列も、起動の手順も、そこで案内されます。

## 8. うまくいかないとき

上から順に確かめてください。**多い順に並べてあります。**

**① 完全終了していない**
いちばん多い原因です。「×」で閉じただけになっていませんか。0章の手順で、タスクマネージャーから Claude が消えたことまで確かめてください。

**② 円マークが1つになっている**（経路 B・Windows）
設定ファイルの中では `C:\\Users\\...` と**2つ重ね**ます。1つだと動きません。

**③ 設定ファイルを間違えている**（経路 B・Windows）
書いても何も変わらないときは、もう一方のファイルが本物かもしれません。3章の手順1に戻って、両方の場所を確かめてください。

**④ 一覧から追加したのに、設定ファイルに出てこない**
故障ではありません。一覧から入れたものと、設定ファイルに書いたものは、**別の場所に保存されます**。片方に出てくるものは、もう片方には出てきません。どちらの入れ方でも動きます。

**⑤ フォルダが見つからないと言われる**
見せるフォルダの綴りを確認してください。空白や日本語が入っていても構いませんが、**一字一句そのまま**である必要があります。

**⑥ `npx` が無いと言われる**（経路 B）
Node.js が入っていません。[nodejs.org](https://nodejs.org/) の LTS 版を入れてから、完全終了 → 起動でやり直してください。

**⑦ それでもだめなとき —— 記録を見る**
`Windows キー` + `R` で次を貼り付けると、記録のフォルダが開きます。

```
%APPDATA%\Claude\logs
```

`mcp.log` と `mcp-server-filesystem.log` を開き、**中身をそのまま Claude に貼り付けて**「これはどういう意味ですか」と聞いてください。読み解いて教えてくれます。
