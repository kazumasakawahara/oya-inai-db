# はじめての方のためのユーザーマニュアル（Windows対応）

> **対象読者**: パソコンが特別得意でなくても大丈夫。障害福祉の現場で働く支援員・相談員の方が、
> このシステム（nest-support）を「導入」して「毎日の仕事で使う」ところまでを、
> 順番どおりにたどれるように書いています。
>
> **このマニュアルのゴール**: あなたが Claude（クロード）に日本語で話しかけるだけで、
> クライアントの大切な情報を安全に記録・確認できるようになること。
>
> Mac をお使いの方は基本の流れは同じです。細かいコマンドは [QUICK_START.md](./QUICK_START.md) を参照してください。

## 1. このシステムでできること

**nest-support** は、「親なき後」も途切れない支援のために、
クライアント一人ひとりの大切な情報を、**話しかけるだけで**記録・整理・確認できる仕組みです。

たとえば、こんなことができます。

- 🚫 **禁忌事項の確認** — 「絶対にしてはいけないこと」を緊急時にすぐ引き出せる（最重要）
- 📝 **支援記録の登録** — 訪問メモを自然な文章のまま入力するだけで、自動で整理されて保存される
- 👥 **緊急連絡先の確認** — キーパーソン・かかりつけ医・後見人を優先順位つきで表示
- 🗓️ **訪問前ブリーフィング** — 前回の記録や注意点をまとめて準備
- ⏰ **更新期限の管理** — 手帳・受給者証の更新漏れを防ぐ
- 🔎 **事業所検索・口コミ** — サービス事業所の情報を横断検索

**難しいパソコン操作は要りません。** あなたは Claude Desktop という無料アプリに、
ふだんの言葉で話しかけるだけです。裏側でデータベース（Neo4j）が情報を安全に保管します。

> **たとえるなら**: Claude は「よく気のつくベテラン相談員」、
> データベースは「鍵のかかった頑丈なキャビネット」です。
> あなたが口頭で頼むと、Claude がキャビネットから正確な書類を出してくれます。

## 2. 使う前に用意するもの

インストールの前に、次の3つを準備します（すべて無料です）。
何をするアプリなのか、かんたんに説明します。

| 用意するもの | これは何？ | 必須 |
|------------|-----------|:---:|
| **Claude Desktop** | あなたが話しかける相手。AIアシスタントのアプリ | ○ |
| **Docker Desktop** | データベースを動かすための「土台」アプリ。普段は起動しておくだけ | ○ |
| **Node.js** | Claude とデータベースをつなぐ「配線」。裏で動くだけで操作は不要 | ○ |

- **パソコンの条件**: Windows 10 または 11、メモリ 8GB 以上を推奨。
- **管理者権限**: インストール時に「管理者として実行」が必要です（会社のPCの場合は情報システム担当に相談してください）。
- **インターネット接続**: インストール時と、AIが考えるときに必要です。

> 💡 これらを一つずつ手で入れるのは大変なので、**次の章のインストーラーが自動で案内**してくれます。

## 3. インストール（初回だけ・約30分）

初回のみ行う作業です。一度終われば、次回からは「起動」だけで使えます。

### ステップ 3-1: PowerShell を「管理者として実行」で開く

1. 画面左下の Windows マーク（スタート）を右クリック
2. メニューから **「ターミナル（管理者）」** または **「Windows PowerShell（管理者）」** を選ぶ
3. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **「はい」**

黒い（または青い）文字入力の画面が開けば成功です。

### ステップ 3-2: インストーラーを実行する

開いた画面に、次の2行を**1行ずつコピー＆貼り付け**して、それぞれ Enter を押します。

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
```

```powershell
irm https://raw.githubusercontent.com/kazumasakawahara/nest-support/main/installer/install-windows.ps1 | iex
```

> 貼り付けは、画面内で**右クリック**すると行えます（Ctrl+V が効かない場合があります）。

すでにこのシステムのフォルダをパソコンに保存してある場合は、代わりにそのフォルダへ移動して実行します:

```powershell
cd $env:USERPROFILE\Documents\nest-support
.\installer\install-windows.ps1
```

### ステップ 3-3: 画面の案内に従う

インストーラーが自動で次のことを行います。**質問が出たら、基本は Enter（＝はい）でOK**です。

1. Docker Desktop・Node.js が入っているか確認（無ければ入れ方を案内）
2. 本体プログラムのダウンロード（保存先: `ドキュメント\nest-support`）
3. データベース（Neo4j）の起動
4. Claude 用の「スキル」13種類のインストール
5. Claude Desktop への接続設定の追加
6. **デモデータを入れますか？** → 練習したい方は「はい」（架空の人物データで安全に試せます）
7. 接続テスト

途中で Docker Desktop のインストールを促された場合は、指示どおりインストール後、
**パソコンを再起動してから**もう一度ステップ 3-2 を実行してください。

### ステップ 3-4: Claude Desktop を再起動して確認

1. Claude Desktop をいったん**完全に終了**（ウィンドウを閉じるだけでなく、タスクトレイからも終了）
2. もう一度 Claude Desktop を起動
3. 入力欄の近くにある**ツール（🔧）のアイコン**に **`neo4j`** と表示されていれば成功です 🎉

うまく表示されないときは → [9. 困ったときは](#9-困ったときはトラブル対処)

## 4. 毎日の起動と終了

インストールが終われば、毎日の準備はとてもシンプルです。

### 朝（使い始めるとき）

1. **Docker Desktop を起動**する（スタートメニューから。クジラのマークのアプリ）
   - 起動して 1〜2 分待つと、データベースが自動で立ち上がります（自動復帰する設定済み）。
2. **Claude Desktop を起動**する。
3. これだけで準備完了。あとは話しかけるだけです。

> Docker Desktop は起動しておくだけで、あなたが操作する必要はありません。
> パソコンのスタートアップに登録しておくと、毎朝自動で立ち上がって便利です。

### 夜（終わるとき）

- 特別な操作は不要です。パソコンをそのままシャットダウンして構いません。
- データは自動的に保存され、消えません。

## 5. 基本の使い方 — Claude に話しかける

使い方の基本は、たった1つ。

> **Claude Desktop の入力欄に、ふだんの言葉で、やりたいことを書く。**

コツは3つだけです。

1. **クライアントの名前を入れる** — 「山本翔太さんの…」のように、誰の話かを伝える
2. **やりたいことを素直に書く** — 「〜を教えて」「〜を記録して」「〜を準備して」
3. **わからなければ聞く** — 「使い方を教えて」「何ができるか一覧を見せて」

Claude が、13種類ある専門「スキル」の中から、あなたの用件に一番合うものを**自動で選んで**答えます。
どのスキルを使うか、あなたが覚える必要はありません。

> ⚠️ **AIは「推測で作り話」をしない設計**です。情報が無いときは「記録がありません」と答えます。
> 逆に言うと、**登録していないことは出てきません**。大切なことは必ず記録しましょう。

## 6. よく使う7つの操作

そのままコピーして使える「話しかけ例」を並べました。名前の部分をあなたの担当者に置き換えてください。

### 操作1: 新しいクライアントを登録する

> 新しいクライアントを登録したい

対話形式で、①氏名・生年月日 → ②禁忌事項（最重要）→ ③配慮事項 → ④キーパーソン → ⑤かかりつけ医、の順に聞き取りを案内します。
**全部を一度に入力しなくても大丈夫。** わかる範囲から登録して、あとで追加できます。

### 操作2: 緊急情報をすぐ確認する（★関わる前に必ず）

> 山本翔太さんの緊急情報を教えて

重要な順（①禁忌事項 → ②推奨ケア → ③緊急連絡先 → ④かかりつけ医 → ⑤後見人）に表示されます。
**新しい職員がクライアントに関わる前には、必ずこれを確認してください。**

### 操作3: 訪問前のブリーフィングを受ける

> 山本翔太さんの訪問準備をして

前回の記録・注意点・最近の変化・今回の確認ポイントがまとめて出ます。訪問の前日〜当日にどうぞ。

### 操作4: 支援記録を残す

> 山本翔太さんの支援記録を追加:
> 今日の訪問で、新しい絵を見せてくれた。
> 母から相談：来月の手帳更新について心配している。
> 次回は更新手続きの準備を一緒に行う予定。

日常のできごとを**自然な文章のまま**入力するだけ。自動で整理されて保存されます。

### 操作5: 更新期限を確認する（月1回おすすめ）

> 更新期限が近い手帳・受給者証を確認して

今後90日以内に更新が必要なものが一覧で出ます。更新漏れは本人の不利益に直結します。

### 操作6: 事業所を探す・口コミを見る

> 〇〇市の生活介護の事業所を探して
> △△事業所の口コミを見せて

### 操作7: 使い方に迷ったとき

> 使い方がわからないので教えて

## 7. スマホから記録する（現場UI・任意）

外出先や移動中にスマホから記録したい場合は、「現場UI」という画面も使えます（設定した場合のみ）。

- 支援記録の入力フォーム
- 音声のワンタップ録音（あとで自動で文字起こし）
- 管理者向けダッシュボード

導入・URL の発行は職場の管理担当者に確認してください。
音声記録の詳しい使い方は [VOICE_RECORDING_GUIDE.md](./VOICE_RECORDING_GUIDE.md) を参照してください。

> 現場UI はログイン（認証）が必要です。緊急通報（SOS）だけは、緊急時にすぐ使えるよう
> あえてログイン不要にしていますが、その分、氏名などの個人情報は表示されない設計です。

## 8. 個人情報を守るための約束

このシステムは、障害のある方やご家族の**非常にデリケートな情報**を扱います。次の約束を守ってください。

**やること**
- ✅ パソコンには必ず**ログインパスワード**をかける
- ✅ 画面を離れるときは**画面ロック**（Windows キー + L）
- ✅ 記録は**事実だけ**を書く（憶測や個人的な評価は分けて考える）
- ✅ データの持ち出し・共有は、職場のルールに従う

**やってはいけないこと**
- ❌ クライアントの情報を、個人のメールや SNS・チャットに貼り付けて外部に送る
- ❌ 家族の健康情報や、クライアントの個人情報を、無関係な人に見せる
- ❌ パスワードを付箋でモニターに貼る／同僚と共有する

> 研修やデモで画面を見せるときは、**仮名化（名前を伏せる）機能**が使えます。
> 詳しくは管理担当者、または [PRIVACY_GUIDELINES.md](./PRIVACY_GUIDELINES.md) を参照してください。

## 9. 困ったときは（トラブル対処）

まず試してほしいのは、**Docker Desktop と Claude Desktop の両方を再起動する**ことです。
多くの不調はこれで直ります。それでもダメなときは、症状別に下を見てください。

### 「neo4j」ツールが Claude に表示されない

1. Docker Desktop が起動しているか確認（クジラのマークが緑色）
2. Claude Desktop を**完全に終了**して、もう一度起動
3. それでも出ないときは、PowerShell で設定を入れ直す:
   ```powershell
   cd $env:USERPROFILE\Documents\nest-support
   .\installer\configure-claude.ps1
   ```

### データベースに繋がらない・エラーが出る

PowerShell で次を実行して、データベースを再起動します:

```powershell
cd $env:USERPROFILE\Documents\nest-support
docker compose restart
```

ブラウザで <http://localhost:7474> を開き、画面が出れば動いています（ユーザー名 `neo4j` / パスワード `password`）。

### スキルが認識されない

```powershell
dir $env:USERPROFILE\.claude\skills\
.\setup.ps1 -Skills
```

### 「話しかけても、情報がありません と言われる」

それは故障ではなく、**まだ登録されていない**可能性が高いです。
[操作1・操作4](#6-よく使う7つの操作)で登録してから、もう一度確認してください。

### それでも解決しないとき

- よくある質問と対処をまとめた [FAQ.md](./FAQ.md) を見る
- 職場の管理担当者に、**画面に出ているエラー文をそのまま**伝える（スクリーンショットが便利）
