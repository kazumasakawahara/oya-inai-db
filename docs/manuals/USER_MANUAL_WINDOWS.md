# はじめての方のためのユーザーマニュアル（Windows対応）

> **対象読者**: パソコンが特別得意でなくても大丈夫。障害福祉の現場で働く支援員・相談員の方が、
> このシステム（親亡き後支援データベース / oya-inai-db）を「導入」して「毎日の仕事で使う」ところまでを、
> 順番どおりにたどれるように書いています。
>
> **このマニュアルのゴール**: あなたがブラウザで画面を開き、
> クライアントの大切な情報を安全に記録・確認できるようになること。
>
> Mac をお使いの方は基本の流れは同じです。細かいコマンドは [QUICK_START.md](./QUICK_START.md) を参照してください。

## 1. このシステムでできること

**親亡き後支援データベース** は、「親亡き後」も途切れない支援のために、
クライアント一人ひとりの大切な情報を、パソコンの画面から記録・整理・確認できる仕組みです。

たとえば、こんなことができます。

- 🚫 **禁忌事項の確認** — 「絶対にしてはいけないこと」を緊急時にすぐ引き出せる（最重要）
- 📝 **記録の登録** — 出来事の記録・面談記録を、画面の順番どおりに入力するだけで保存される
- 👥 **緊急連絡先の確認** — キーパーソン・かかりつけ医・後見人を優先順位つきで表示
- 🗓️ **訪問前ブリーフィング** — 前回の記録や注意点をまとめて準備
- ⏰ **更新期限の管理** — 手帳・受給者証の更新漏れを防ぐ
- 🕸️ **エコマップ・知識グラフ** — 支援のつながりを図で確認

**難しいパソコン操作は要りません。** あなたはブラウザで <http://localhost:3001> を開き、
左のメニューから使いたい画面を選ぶだけです。裏側でデータベース（Neo4j）が情報を安全に保管します。

> **たとえるなら**: 画面は「よく整理された受付カウンター」、
> データベースは「鍵のかかった頑丈なキャビネット」です。
> あなたがカウンターで頼むと、必要な書類が正確に出てきます。

### 「ソフトは無償・AI は Claude」という考え方

このソフトウェア自体は無償で、Web 画面の機能は **AI をまったく設定しなくても動きます**。
一方、**新しい方の登録**と、語り・文書からの**まとめ入力**は、**Claude**（Anthropic 社の AI アシスタント）に
頼む設計です（Claude の有料プランの契約が実質的な導入要件になります）。

| Web 画面でできること（Claude 不要） | Claude が担当すること（要設定 → 7章） |
|--------------------------|----------------------------|
| 利用者台帳（クライアント一覧・詳細） | 新しい方の登録 |
| 緊急照会（禁忌事項・連絡先） | 語り・文書からのまとめ入力 |
| 更新期限アラート | 自由な言葉での照会・記録の検索 |
| 出来事の記録・面談記録 | 書類の下書き作成 |
| エコマップ・知識グラフ | — |

Claude の設定をしていなくても**エラーにはなりません**。まずは Web 画面だけで使い始めて構いません。

## 2. 使う前に用意するもの

インストールの前に、次の2つを準備します（どちらも無料です）。
何をするアプリなのか、かんたんに説明します。

| 用意するもの | これは何？ | 必須 |
|------------|-----------|:---:|
| **Docker Desktop** | データベースを動かすための「土台」アプリ。普段は起動しておくだけ | ○ |
| **Node.js** | Web画面（ブラウザで開く画面）を動かすための部品。裏で動くだけで操作は不要 | ○ |
| **Claude 有料プラン + Claude Desktop** | 新しい方の登録・まとめ入力に使う AI（→ 7章） | 登録する人のみ |

- **パソコンの条件**: Windows 10 または 11、メモリ 8GB 以上を推奨。
- **管理者権限**: インストール時に必要になることがあります（会社のPCの場合は情報システム担当に相談してください）。
- **インターネット接続**: インストール時に必要です。使い始めたあとは、Web 画面での閲覧・記録はオフラインでも動きます（Claude に頼むときは接続が必要）。

> 💡 これらを一つずつ手で入れるのは大変なので、**次の章のインストーラーが自動で案内**してくれます。

## 3. インストール（初回だけ）

初回のみ行う作業です。一度終われば、次回からは「起動」だけで使えます。所要時間の目安は 10〜20分です。

### ステップ 3-1: PowerShell を開く

1. 画面左下の Windows マーク（スタート）を右クリック
2. メニューから **「ターミナル」** または **「Windows PowerShell」** を選ぶ
3. 「このアプリがデバイスに変更を加えることを許可しますか？」と出たら **「はい」**

黒い（または青い）文字入力の画面が開けば成功です。

### ステップ 3-2: インストーラーを実行する

開いた画面に、次の2行を**1行ずつコピー＆貼り付け**して、それぞれ Enter を押します。

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
```

```powershell
irm https://raw.githubusercontent.com/kazumasakawahara/oya-inai-db/main/installer/install-windows.ps1 | iex
```

> 貼り付けは、画面内で**右クリック**すると行えます（Ctrl+V が効かない場合があります）。

すでにこのシステムのフォルダをパソコンに保存してある場合は、代わりにそのフォルダへ移動して実行します:

```powershell
cd $env:USERPROFILE\Documents\oya-inai-db
.\installer\install-windows.ps1
```

### ステップ 3-3: 画面の案内に従う

インストーラーが自動で次のことを行います。**質問が出たら、基本は Enter（＝はい）でOK**です。

1. **前提条件の確認** — Docker Desktop・Node.js が入っているか確認（無ければ入れ方を案内）
2. **本体プログラムの取得** — 保存先: `ドキュメント\oya-inai-db`
3. **データベース（Neo4j）の起動**
4. **接続テスト**

途中で Docker Desktop のインストールを促された場合は、指示どおりインストール後、
**パソコンを再起動してから**もう一度ステップ 3-2 を実行してください。

### ステップ 3-4: 設定ファイル（.env）を用意する

`.env.example` を `.env` という名前でコピーします。

```powershell
cd $env:USERPROFILE\Documents\oya-inai-db
copy .env.example .env
```

中身は、はじめのうちは触らなくて構いません。書かれている項目は次の3つです。

| 項目 | 意味 |
|------|------|
| `NEO4J_URI` | データベースの場所（`bolt://localhost:7687` のまま） |
| `NEO4J_USERNAME` | `neo4j` のまま |
| `NEO4J_PASSWORD` | `password` のまま |

### ステップ 3-5: 練習用のデモデータを入れる（おすすめ）

架空の人物のデータ（合成データ）なので、安心して操作の練習ができます。

```powershell
cd $env:USERPROFILE\Documents\oya-inai-db
.\installer\load-demo-data.ps1
```

### ステップ 3-6: 起動して画面を確認する

エクスプローラーで `ドキュメント\oya-inai-db` フォルダを開き、**`start.bat` をダブルクリック**します。
黒い画面が出て準備が進み、しばらくするとブラウザで次のアドレスが開けるようになります。

- **アプリの画面**: <http://localhost:3001>

ホーム（ダッシュボード）が表示されれば成功です 🎉

うまく表示されないときは → [9. 困ったときは](#9-困ったときはトラブル対処)

## 4. 毎日の起動と終了

インストールが終われば、毎日の準備はとてもシンプルです。

### 朝（使い始めるとき）

1. **Docker Desktop を起動**する（スタートメニューから。クジラのマークのアプリ）
   - 起動して 1〜2 分待ちます。
2. **`start.bat` をダブルクリック**する。
3. ブラウザで <http://localhost:3001> を開く。

> よく使うので、ブラウザのブックマーク（お気に入り）に登録しておくと便利です。

### 夜（終わるとき）

- **`stop.bat` をダブルクリック**すると、きれいに終了します。
- そのままパソコンをシャットダウンしても構いません。データは自動的に保存され、消えません。

## 5. 基本の使い方 — 画面のどこに何があるか

ブラウザで <http://localhost:3001> を開くと、**左側にメニュー（サイドバー）**が並んでいます。
やりたいことに応じて、次の画面を選びます。

| メニュー | どんなときに使うか |
|---------|-------------------|
| **ホーム** | 全体の状況をひと目で見る（ダッシュボード） |
| **出来事の記録** | その日の様子を短く記録する |
| **面談記録** | 面談の内容を残す（文字入力・文書ファイル） |
| **クライアント一覧** | 登録された方を探す・詳細を見る・緊急照会 |
| **エコマップ** | 支援のつながりを図で見る |
| **知識グラフ** | 情報どうしの関係を図で見る |

> **新しい方の登録画面はありません。** 新しいクライアントの登録と、語り・文書からのまとめ入力は、
> Claude に頼みます（→ [7章](#7-claude-を使いたいとき登録まとめ入力)）。

### 入力画面の共通ルール

入力する画面は、**番号のついたステップ（① → ② → …）**の順に進みます。

- 上から順に埋めていけば完成します。
- まだ足りない項目があると、ボタンの近くに
  **「あと「◯◯」を済ませると押せます」**というヒントが出ます。そこを埋めれば先に進めます。

> ⚠️ このシステムは**登録されていないことは表示しません**。
> 「記録がありません」と出るのは故障ではなく、まだ入力されていないという意味です。
> 大切なことは必ず記録しましょう。

## 6. よく使う操作

### 操作1: 新しいクライアントを登録する（Claude に頼む）

登録は画面ではなく **Claude Desktop** に、ふだんの言葉で頼みます（設定は [7章](#7-claude-を使いたいとき登録まとめ入力)）。
氏名・生年月日のほか、禁忌事項（最重要）・配慮事項・キーパーソン・かかりつけ医を伝えます。

**全部を一度に伝えなくても大丈夫。** わかる範囲で登録して、あとから Claude に追加を頼めます。
登録できたかは、**クライアント一覧**で目で確認してください。

### 操作2: 緊急情報をすぐ確認する（★関わる前に必ず）

**クライアント一覧**から対象の方を選び、詳細を開きます。
重要な順（①禁忌事項 → ②推奨ケア → ③緊急連絡先 → ④かかりつけ医 → ⑤後見人）に確認してください。

**新しい職員がクライアントに関わる前には、必ずこれを確認してください。**

### 操作3: 訪問前のブリーフィングを受ける

**ホーム（ダッシュボード）**とクライアント詳細で、前回の記録・注意点・最近の変化を確認します。
訪問の前日〜当日に目を通しておくと安心です。

### 操作4: その日の様子を記録する（出来事の記録）

**出来事の記録**を開き、番号順に選んでいきます。

1. **本人の様子**を絵文字ボタンから選ぶ
2. **場面**（どんな場面だったか）を選ぶ
3. **環境**（まわりの状況）を選ぶ
4. **詳細**を書く
5. 必要なら**職員の対応**を書く（任意）

選ぶだけで進むので、忙しい現場でも短時間で残せます。

### 操作5: 面談の内容を残す（面談記録）

**面談記録**では、次の2つのやり方から選べます。

- **その場で文字入力する** — 画面に直接打ち込む
- **文書ファイルを添付する** — すでに作ってある記録ファイルを添付する

まとまった語りを整理して登録したいときは、文章ごと Claude に渡して**まとめ入力**を頼めます（→ [7章](#7-claude-を使いたいとき登録まとめ入力)）。

### 操作6: 更新期限を確認する（月1回おすすめ）

**ホーム（ダッシュボード）**に、更新期限が近い手帳・受給者証のアラートが出ます。
更新漏れは本人の不利益に直結します。月に1回は目を通しましょう。

### 操作7: 支援のつながりを図で見る

**エコマップ**で、その方を取り巻く人・機関のつながりを確認できます。
**知識グラフ**では、登録された情報どうしの関係を広く見渡せます。

## 8. 個人情報を守るための約束

このシステムは、障害のある方やご家族の**非常にデリケートな情報**を扱います。次の約束を守ってください。

**やること**
- ✅ パソコンには必ず**ログインパスワード**をかける
- ✅ 画面を離れるときは**画面ロック**（Windows キー + L）
- ✅ 記録は**事実だけ**を書く（憶測や個人的な評価は分けて考える）
- ✅ データの持ち出し・共有は、職場のルールに従う
- ✅ Claude を使うなら、[7章](#7-claude-を使いたいとき登録まとめ入力)を読んで**どこにデータが行くか**を確認する

**やってはいけないこと**
- ❌ クライアントの情報を、個人のメールや SNS・チャットに貼り付けて外部に送る
- ❌ 家族の健康情報や、クライアントの個人情報を、無関係な人に見せる
- ❌ パスワードを付箋でモニターに貼る／同僚と共有する

> 詳しくは管理担当者、または [PRIVACY_GUIDELINES.md](./PRIVACY_GUIDELINES.md) を参照してください。

## 9. 困ったときは（トラブル対処）

まず試してほしいのは、**Docker Desktop を起動し直してから `start.bat` をもう一度実行する**ことです。
多くの不調はこれで直ります。それでもダメなときは、症状別に下を見てください。

### 画面が開かない／ localhost:3001 につながらない

1. Docker Desktop が起動しているか確認（タスクバーのクジラのマーク）
2. `stop.bat` を実行してから、もう一度 `start.bat` をダブルクリック
3. 起動には少し時間がかかります。1〜2分待ってからブラウザを再読み込み（F5）
4. それでもダメなら、下の「データベースの状態を確認する」へ

### データベースの状態を確認する

PowerShell で次を実行します。

```powershell
docker ps
```

一覧に **`oya-inai-db-neo4j`** があれば、データベースは動いています。無ければ `start.bat` を実行し直してください。

もっと詳しく調べるときは、エラーの記録を見ます。

```powershell
docker logs oya-inai-db-neo4j
```

ブラウザで <http://localhost:7474> を開き、画面が出ればデータベースは応答しています
（ユーザー名 `neo4j` / パスワード `password`）。

### まとめて自動診断する

Mac をお使いの場合、次のコマンドで一括診断できます。

```bash
./scripts/doctor.sh
```

### 「記録がありません」と表示される

それは故障ではなく、**まだ登録されていない**可能性が高いです。
[操作1・操作4・操作5](#6-よく使う操作)で登録してから、もう一度確認してください。

### Claude がデータベースにつながらない

1. Docker Desktop と `start.bat` でシステムが動いているか確認する（上の「データベースの状態を確認する」）
2. MCP の設定を変えた直後なら、Claude Desktop を**完全終了**してから開き直す
3. それでも直らなければ [../mcp-setup.md](../mcp-setup.md) のトラブルシューティングへ（[7章](#7-claude-を使いたいとき登録まとめ入力)）

Web 画面の機能は Claude なしでもそのまま使えます。

### Windows で「スクリプトの実行が無効」と言われる

PowerShell で次を実行してから、もう一度スクリプトを実行してください。

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
```

### それでも解決しないとき

- よくある質問と対処をまとめた [FAQ.md](./FAQ.md) を見る
- 職場の管理担当者に、**画面に出ているエラー文をそのまま**伝える（スクリーンショットが便利）
