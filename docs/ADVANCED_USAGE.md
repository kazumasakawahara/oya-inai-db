# 発展的運用ガイド

基本操作（記録・照会）に慣れたあと、Claude との連携や可視化を活用するためのガイドです。セットアップは [QUICK_START.md](./QUICK_START.md) を参照してください。

---

## アーキテクチャ概要

| レイヤー | ツール | 役割 |
|:--|:--|:--|
| **Next.js フロントエンド** | ブラウザUI（port 3001） | ダッシュボード・記録・照会・可視化 |
| **FastAPI バックエンド** | API（port 8001） | REST API（照会・記録・可視化） |
| **Neo4j** | グラフDB（Docker, port 7687） | すべての支援データの保存先 |
| **Claude Desktop + MCP** | 外部アプリ（任意） | 新しい方の登録・まとめ入力・自由な言葉での照会 |

AI は **Claude 一本**です（2026-08 方針決定。旧 Ollama / Gemini の選択制・LLM設定画面は廃止）。**Claude 未設定でも Web 画面の機能はすべて動作します。**

---

## Claude での照会・分析（要 MCP 設定）

Claude Desktop をデータベースにつなぐと（→ [mcp-setup.md](./mcp-setup.md)）、データベースの内容について自然な日本語で質問できます。

**照会・分析:**
```
山田健太さんのプロフィールを表示して
```
```
更新期限が近い証明書を全クライアント分チェックして
```
```
佐藤さんの最近の支援記録を分析して、効果的だったケアパターンを教えて
```

**緊急時（禁忌→推奨ケア→連絡先の順で返ります）:**
```
田中さんがパニックを起こしています。緊急対応情報をください。
```

> 緊急照会は AI を経由しない Web 画面でも提供されます（クライアント詳細の緊急照会。Claude 未設定でも使えます）。**急ぐときはそちらが確実です。**

## 事業所検索（ServiceProvider）

WAM NET 由来の事業所データを取り込んでいる場合、Claude に頼んで検索できます:

```
北九州市の生活介護事業所で空きのあるところを探して
```
```
山田さんの就労B型の代替事業所を探して。現在の事業所が閉鎖予定のため。
```

口コミは ◎○△× の4段階で登録・参照できます。

## エコマップ（支援関係の可視化）

「エコマップ」ページから GUI で生成・ダウンロードできます（draw.io 形式。draw.io アプリで自由に編集可能）。

**4つのテンプレート:**

| テンプレート | 用途 |
|-------------|------|
| `full_view` | 包括的な全体像（初回面談時） |
| `support_meeting` | サービス担当者会議用 |
| `emergency` | 緊急時体制（Safety First） |
| `handover` | 引き継ぎ用（履歴含む) |

「知識グラフ」ページでは、データベース全体のつながりをそのまま探索できます。

## 記録を意味で探したいとき

旧バージョンの「記録を探す」ページ（意味検索）は廃止しました。かわりに:

- **キーワードの一致で探す** → 各クライアント詳細ページの記録一覧を使う
- **意味の近い記録を探す**（例:「大きな声」で「叫んでいた」の記録も拾いたい）→ **Claude に頼む**。Claude がデータベースから該当しそうな記録を取得して読み、意味で絞り込みます

```
佐藤さんの記録から、大きな声・叫び声に関係する出来事を探して
```

## リポジトリ構成の補足（開発者向け）

`agents/` には運用プロトコル・ワークフローの文書（Markdown）が、`skills/` にはエコマップ生成・レポート出力などの Python モジュールが含まれます。

スキーマの正典は `docs/SCHEMA_CONVENTION.md` / `docs/SEMANTIC_MODEL.md`（shared-schema からの同期コピー・直接編集禁止）です。

## トラブルシューティング

### 画面（localhost:3001）が開かない

```bash
./scripts/doctor.sh              # 一括診断
```

`start.command`（Mac）/ `start.bat`（Windows）を再実行してください。

### Neo4j に接続できない

```bash
docker ps | grep neo4j
docker logs oya-inai-db-neo4j
docker compose restart neo4j
```

### Cypher クエリを直接確認したい

1. Neo4j Browser (http://localhost:7474) で直接クエリを実行（認証: neo4j / password）
2. スキーマ（ラベル・リレーション・プロパティ名）は `docs/SCHEMA_CONVENTION.md` と一致しているか確認
